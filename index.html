Thunar-connection

A personal Google Drive connection used by AlekseiTovkachev on a Linux computer.

This OAuth application allows rclone to provide access to the owner's Google Drive through a mounted folder, which can be browsed using the Thunar file manager.

What it does

After the owner authorizes access with Google, rclone can list, open, download, upload, create, modify, move, and delete Drive files in response to the owner's file operations. Local caching is used for file access.

This application is for the owner's personal use. It is not a public file-sharing service and is not an official Google or Xfce application.
