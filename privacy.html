Privacy policy

Application: Thunar-connection
Operator: AlekseiTovkachev
Updated: 27 October 2026

This is a personal OAuth application used to connect the operator's Google Drive to rclone on the operator's Linux computer.

Information accessed and its purpose

With the operator's Google authorization, rclone accesses Drive file names, folder structure, file metadata, file contents, and storage information. This enables browsing, downloading, uploading, creating, modifying, moving, and deleting files as requested by the operator.

Storage and retention

OAuth credentials and tokens are stored in rclone's configuration on the operator's computer. File metadata and file content may be stored in rclone's local cache. Local configuration and cached data remain until removed or cleared under the local application's settings.

Sharing and processing

Drive requests are made to Google's services to perform the requested operations. This personal application does not sell Google user data, use it for advertising, or intentionally share it with other users or third-party services. Accessing files with other applications or sharing them is controlled by the operator.

Control and revocation

The operator can revoke this application's authorization through Google Account connections. Revoking access prevents further authorized API access, but does not itself erase copies or caches already stored on the local computer.

This informational website

These pages contain no sign-in form, analytics scripts, or application credentials. They are hosted by GitHub Pages, whose handling of website requests is covered by the GitHub privacy statement.

Contact

Questions about this personal application can be raised in the project issue tracker. Do not include credentials, tokens, or private Drive information in public issues.
